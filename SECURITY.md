# Security Policy — NYVEX

## Сообщить об уязвимости

Напишите на **abrorismurzaev2@gmail.com** с темой `[SECURITY] NYVEX`.

Пожалуйста, укажите:
- описание уязвимости;
- шаги воспроизведения;
- возможное влияние;
- (опционально) PoC без вредоносного использования.

Мы стараемся ответить в течение **72 часов**.

## Responsible disclosure

- Не публикуйте детали до исправления.
- Не эксплуатируйте уязвимость на реальных пользователях.
- Мы не преследуем добросовестных исследователей, действующих в рамках этой политики.

## Scope (входит)

- Сайт приложения: `https://abrorismurzaev2-cpu.github.io/nyvex/`
- Лендинг: `https://abrorismurzaev2-cpu.github.io/nyvex-landing/`
- Клиентский код (HTML/JS/CSS), Service Worker
- Android APK, собираемый из этого репозитория
- Будущий backend оплаты (YooKassa), если будет развёрнут

## Out of scope (не входит)

- Атаки на инфраструктуру GitHub / GitHub Pages
- DoS / DDoS
- Социальная инженерия
- Уязвимости сторонних CDN (jsDelivr, Hugging Face) без влияния на NYVEX
- Отчёты из автоматических сканеров без подтверждённого impact

## Известные ограничения

- Аккаунт и чаты хранятся **только в localStorage** браузера (клиентское приложение).
- Секреты платёжного API **не** должны попадать во frontend; оплата — только через backend.
- Публичный репозиторий: любые «секреты» в коде считаются скомпрометированными.

## Награды

Отдельной bug bounty программы пока нет. Критичные отчёты приветствуются.
